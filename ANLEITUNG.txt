SCHIEBEPUZZLE WEB-APP - QUICK START
====================================

Diese Datei ist die kurze Startanleitung fuer die lokale Windows-Nutzung.
Ausfuehrlichere technische Hinweise stehen in README.md.


STARTEN
-------

1. start.bat doppelt anklicken
   - installiert beim ersten Start automatisch die npm-Abhaengigkeiten
   - startet den Vite-Entwicklungsserver mit "npm run dev"
   - oeffnet die App unter http://127.0.0.1:5173/

2. Wenn der Server bereits laeuft
   - start.bat erkennt die bestehende Schiebepuzzle-Instanz
   - der Browser wird direkt erneut geoeffnet


BUILD ERSTELLEN
---------------

build.bat doppelt anklicken
   - installiert fehlende npm-Abhaengigkeiten
   - fuehrt "npm run build" aus
   - schreibt den Production-Build in den Ordner dist/


VORAUSSETZUNGEN
---------------

- Windows 10 oder Windows 11
- Node.js inklusive npm
- moderner Browser, zum Beispiel Edge, Chrome oder Firefox

Pruefen, ob npm vorhanden ist:

  npm --version


OPTIONALE API-SCHLUESSEL
------------------------

Fuer einige externe Bild- und Musikquellen kann eine lokale .env-Datei aus
.env.example angelegt werden:

  VITE_JAMENDO_CLIENT_ID=...
  VITE_PEXELS_API_KEY=...
  VITE_PIXABAY_API_KEY=...
  VITE_SMITHSONIAN_API_KEY=...

Ohne diese Schluessel bleibt die App nutzbar und verwendet Fallbacks oder
Provider ohne Key.


BEDIENUNG
---------

1. App starten und im Startscreen beginnen oder letzte Sitzung fortsetzen.
2. Eigenes Bild hochladen, Zufallsbild laden oder ein Motiv aus Galerie/Saves nutzen.
3. Bild im Crop-Screen zuschneiden und Puzzle-Groesse waehlen.
4. Puzzle mit Maus, Touchpad oder Tastatur spielen.
5. Optional Hinweise, Solver, Musik, Hilfe oder Command Palette verwenden.
6. Nach dem Loesen Statistik und Galerie aktualisieren lassen.
7. Spielstaende, Statistik und Galerie bei Bedarf als Backup sichern.


LOKALE DATEN
------------

- spielstaende/ enthaelt gespeicherte Partien, Statistik und Galerie.
- backups/ enthaelt lokale Backup-Dateien.
- dist/ enthaelt den letzten Production-Build.

Diese Ordner normalerweise nicht von Hand bearbeiten.


TROUBLESHOOTING
---------------

- start.bat findet npm nicht:
  Node.js installieren und ein neues Terminal/Fenster oeffnen.

- Port 5173 ist belegt:
  Die andere Anwendung auf Port 5173 beenden. Der Port ist in vite.config.ts
  bewusst fest auf 127.0.0.1:5173 gesetzt.

- Build schlaegt fehl:
  In PowerShell im Projektordner zuerst "npm install" und danach
  "npm run build" ausfuehren, um die genaue Fehlermeldung zu sehen.
